03 / UI ElementsComponents
Comportamento visível

Componentes em movimento

Cada peça demonstra anatomia, estados, motion e intenção acessível. Hover informa; active confirma; focus nunca desaparece.

Buttons / actions

Botões

  • AnatomiaLabel + ícone opcional; altura 46; padding 20; pill.
  • EstadosDefault, hover −2px, active .975, focus ring 3px, disabled 38%.
  • MotionBeam 700ms; ícone 350ms elastic; glow só no primary.
  • UsoUm primary por contexto. Verbo específico; nunca “Enviar”.
Inputs / controls

Inputs

  • AnatomiaLabel persistente, input 48px, ícone terminal, helper.
  • EstadosHover border; focus Violet + halo; invalid Danger + mensagem.
  • MotionHalo e borda em 250ms; sem layout shift.
  • A11yLabel e helper associados; erro textual; target ≥44px.
Cards / content

Cards

Case / 04
Habitat luminoso

Imagem cinética + narrativa concisa.

  • AnatomiaMeta, título, descrição, mídia; ação cobre o card inteiro.
  • StatesBorder Violet, title +7px, image scale 1.10 e saturação.
  • MotionConteúdo 500ms; imagem 1500ms para peso cinematográfico.
  • UsoUma intenção por card; aspect e altura consistentes na grade.
Navbars / wayfinding

Navbars

  • StatesUnderline direcional; item atual com aria-current.

  • UsoSticky; máximo 6 destinos; foco segue ordem visual.
Sections / layout

Seções

04 / SignalUma ideia por dobra.
  • AnatomiaIndex 3 colunas + heading 9 colunas + body alinhado.
  • SurfacesAluminum, GT Silver ou Ink; grade 44px e glow ambiente.

  • UsoPadding 72 desktop / 28 mobile; divider sempre 1px.
Modals / interruption

Modais

  • AnatomiaTítulo, descrição, close, actions; largura máxima 520px.
  • StatesBackdrop 50% + blur; painel Paper; foco contido.
  • MotionFade 350ms; pop translate/scale 550ms elastic.
  • A11yDialog modal, Escape fecha, foco retorna ao trigger.
Badges / status

Badges

OperacionalNovoAtenção
  • AnatomiaDot opcional + label; padding 7×11; mono 9 uppercase.
  • StatesDefault, status, accent; hover só se interativo.
  • MotionHover −2px + rotate −1°; indicator pode pulsar em live.
  • A11yStatus sempre escrito; cor nunca comunica sozinha.
Tooltips / context

Tooltips

Explica a ação sem repetir o label.
  • AnatomiaTexto curto, caret, Ink surface; 170px mínimo.
  • StatesHover e keyboard focus; nunca contém ação essencial.
  • MotionPop 300ms elastic; translate 8→0; scale .95→1.
  • A11yrole tooltip + aria-describedby; conteúdo também acessível ao foco.
